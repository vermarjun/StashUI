StashUI agent playground

You are the agent. Each call hits the real endpoint and shows exactly what an agent receives.

Role-play a build the way the skill tells an agent to do it:

  1. browse with no kinds: the map of what exists.
  2. browse with up to four kinds, for example site-header, hero, pricing-section, footer.
  3. search for a need a row did not cover. Describe it in plain words; the first line of the reply says how it was read and how many really match.
  4. view your top two. Use the buttons under any result.
  5. + pick what you choose, then Board to see the set together.
  6. Propose opens the page a person approves. Add returns the install command.

The other tab shows the instructions an agent has in its context before it makes its first call.
